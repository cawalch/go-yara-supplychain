# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `go-yara-supplychain` seriously. Because this project is used to detect supply-chain malware and evasion techniques, responsible disclosure is vital.

If you believe you have found a security vulnerability, evasion vector, or false-positive bypass, please report it privately:

- **GitHub Advisory**: Open a private draft security advisory at [github.com/cawalch/go-yara-supplychain/security/advisories/new](https://github.com/cawalch/go-yara-supplychain/security/advisories/new).
- **Direct Contact**: Contact the maintainer privately through GitHub security channels.

Please do not report security vulnerabilities through public GitHub issues or discussions.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
1. A description of the issue or evasion pattern.
2. An isolated test case or reproduction package manifest.
3. The expected verdict vs. actual verdict.
4. Any potential mitigations or suggested rule/feature additions.

We will acknowledge receipt within 48 hours and work with you on a patch before public disclosure.
